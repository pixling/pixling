## 報告と相談

- **アプリの不具合:** [Issues](https://github.com/pixling/pixling/issues/new/choose) の「Bug report / 不具合」フォームへ。
- **CLI・MCP の不具合:** 「Agent / CLI / MCP bug」フォームへ。内容を確認した `pixling doctor --json` の出力を添えてください。
- **ドキュメントの誤り:** 「Documentation / ドキュメント」フォームへ。
- **要望と質問:** [Discussions](https://github.com/pixling/pixling/discussions) へ。要望は Ideas、質問は Q&A。採用した要望をメンテナーが issue にします。
- **脆弱性:** [非公開の脆弱性報告](https://github.com/pixling/pixling/security/advisories/new) へ。利用できなければ [support@pixling.app](mailto:support@pixling.app) にメールしてください。公開の issue・discussion に書かないでください。
- **課金・返金・取引 ID・財布の情報・個人の事情:** [support@pixling.app](mailto:support@pixling.app) にメールしてください。公開の場には書かないでください。

画面やログには、住人・エージェントの会話、ファイル名、Mac のアカウント名が写りえます。投稿前に確認し、必要な情報を伏せてください。投稿はどの言語でも歓迎します。対応は best-effort、返事は日本語か英語です。

ここは受付の repo です。PR は受け付けません。issue または discussion をご利用ください。stale bot は使いません。
